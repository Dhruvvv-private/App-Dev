# JavaScript Beginner Lab – Experiments

This repository contains a collection of beginner-level JavaScript programs covering core concepts such as variables, data types, operators, conditionals, loops, functions, arrays, objects, and strings.

## List of Experiments

1. Write a JavaScript program to print your name, age, branch, and college name using `console.log()`.
2. Write a JavaScript program to demonstrate variables and different data types such as String, Number, Boolean, and Undefined.
3. Write a JavaScript program to perform arithmetic operations (addition, subtraction, multiplication, division, and modulus) on two numbers.
4. Write a JavaScript program to accept two numbers from the user and display their sum.
5. Write a JavaScript program to check whether a given number is positive, negative, or zero using if-else.
6. Write a JavaScript program to check whether a given number is even or odd.
7. Write a JavaScript program to find the largest of three numbers using conditional statements.
8. Write a JavaScript program to print numbers from 1 to 10 using a for loop.
9. Write a JavaScript program to generate the multiplication table of a given number using a loop.
10. Write a JavaScript program to calculate the factorial of a given number using a loop.
11. Write a JavaScript program to demonstrate different types of loops such as for, while, and do-while.
12. Write a JavaScript program to create a function that accepts two numbers and returns their sum.
13. Write a JavaScript program to create functions for calculating the area of a circle, rectangle, and triangle.
14. Write a JavaScript program to create an array of numbers and display all its elements using a loop.
15. Write a JavaScript program to find the largest, smallest, and sum of elements in an array.
16. Write a JavaScript program to demonstrate basic array methods such as `push()`, `pop()`, `shift()`, and `unshift()`.
17. Write a JavaScript program to create an array of student names and search for a particular student.
18. Write a JavaScript program to create a student object containing name, roll number, branch, and marks, and display its details.
19. Write a JavaScript program to demonstrate string operations such as finding length, converting case, extracting characters, and reversing a string.
20. Write a JavaScript program to create a simple student marks program using variables, arrays, functions, loops, and conditional statements.

## How to Run

Each program is written as a standalone `.js` file. To run any file using Node.js:

```bash
node filename.js
```

Some programs that take user input use the [`prompt-sync`](https://www.npmjs.com/package/prompt-sync) package. Install it first if needed:

```bash
npm install prompt-sync
```
